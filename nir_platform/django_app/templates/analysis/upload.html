File Format Instructions

CSV files should have at least two columns: wavelength and intensity.

Example:

wavelength,intensity
700,100
701,105
702,110
...

Text files should have two columns separated by whitespace.

Example:

700 100
701 105
702 110
...

ZIP files can contain multiple spectral data files. The system will automatically extract and analyze all supported files.
