## Overview

The NIR Intelligence Platform provides comprehensive NIR spectroscopy data analysis through a multi-agent architecture.

## Architecture

The platform consists of the following components:

- **Master Orchestrator**: Central coordination and quality control
- **Data Agents**: Data preparation, metadata management, sensor quality
- **Analysis Agents**: Statistical analysis, neural networks, calibration
- **Storage Agents**: Qdrant, FAISS, PostgreSQL for data storage
- **Integration Agents**: Django, MCP, ILIAS, Quarto, Flower
