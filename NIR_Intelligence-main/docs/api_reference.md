# API Reference

This document describes the APIs provided by the NIR Intelligence Platform.

## REST API

The development server provides a REST API for testing agents.

### Endpoints

#### GET /agents

List all available agents.

**Response**:
```json
[
  {
    "name": "DataPreparationAgent",
    "file": "agents/data_preparation_agent.py",
    "loaded": true
  }
]
```

#### GET /agents/{agent_name}

Get information about a specific agent.

**Response**:
```json
{
  "name": "DataPreparationAgent",
  "version": "1.0.0",
  "status": "READY",
  "dependencies": ["pandas", "numpy"],
  "errors": 0
}
```

#### POST /agents/{agent_name}

Execute a specific agent.

**Request Body**:
```json
{
  "iteration": 1,
  "timestamp": 1234567890,
  "data": {}
}
```

**Response**:
```json
{
  "success": true,
  "agent_name": "DataPreparationAgent",
  "status": "COMPLETED",
  "data": {},
  "errors": []
}
```

#### GET /health

Health check endpoint.

**Response**:
```json
{
  "status": "healthy",
  "agents_loaded": 14,
  "timestamp": 1234567890.123
}
```

## Python API

### Agent Base Class

All agents inherit from `BaseAgent` and provide the following interface:

```python
class BaseAgent:
    def __init__(self, name: str, version: str = "1.0.0", **kwargs):
        """Initialize agent"""
    
    def initialize(self) -> AgentOutput:
        """Initialize agent and its environment"""
    
    def execute(self, context: Dict[str, Any]) -> AgentOutput:
        """Execute agent's primary function"""
    
    def validate(self) -> List[AgentError]:
        """Validate agent's current state and configuration"""
```
