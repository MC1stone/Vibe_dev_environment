{% trans "Einführung: Wie messe ich richtig mit Spektroskopie?" %}

{% trans "Für Einsteiger: Was Sie bei der Messung beachten sollten, welche Lichtverhältnisse nötig sind, wie der Schwarz/Weiß-Abgleich funktioniert und welche Metadaten Sie festhalten sollten. Die Angaben berücksichtigen die Sensoren und Einstellungen aus der Sensor-Datenbank dieser Plattform." %}

{% trans "1. Das Grundprinzip in einem Satz" %}

{% trans "Licht trifft auf Ihre Probe (z. B. eine Tomate), ein Teil wird absorbiert und ein Teil reflektiert. Das Spektrometer misst, wie viel Licht bei jeder Wellenlänge zurückkommt — dieses „Farbfingerabdruck“-Muster (das Spektrum) verrät etwas über die Zusammensetzung der Probe, z. B. den Zuckergehalt (Brix)." %}

{% trans "Sichtbares Licht: ca. 380–780 nm. Nahinfrarot (NIR): ca. 780–2500 nm. In beiden Regionen absorbieren Moleküle (Pigmente, Zucker, Wasser) charakteristisch — darauf beruht die Messung." %}

{% trans "Die Spektren-Signale des Sensors sind Rohwerte (ADC-Zahlen) — erst der Vergleich mit Referenzwerten (z. B. Brix aus dem Refraktometer) ergibt eine Kalibration." %}

{% trans "2. Licht und Lichtverhältnisse" %}

{% trans "Das wichtigste bei jeder Spektroskopie-Messung: konsistente Beleuchtung. Ändert sich das Licht zwischen zwei Messungen, ändert sich auch das Spektrum — und Sie können nicht mehr zwischen Probenunterschied und Lichtunterschied unterscheiden." %}

{% trans "So geht's richtig" %}

  • {% trans "Gleichbleibende Lichtquelle: Nutzen Sie wenn möglich die eingebaute Beleuchtung des Sensors (bei Chip-Sensoren meist LED-Onboard) — dann ist das Licht bei jeder Messung identisch." %}
  • {% trans "Tageslicht meiden: Messen Sie nicht direkt am Fenster; wechselndes Sonnenlicht ist der häufigste Fehler." %}
  • {% trans "Umgebung dunkel/gleichmäßig halten: keine flackernden Lampen, keine bewegten Schatten." %}
  • {% trans "Immer gleiche Geometrie: Probenoberfläche, Abstand und Ausrichtung gleich halten." %}

{% trans "Häufige Fehler" %}
  • {% trans "Erste Messung am Morgen, zweite am Abend (anderes Licht)" %}
  • {% trans "Teilweise im Schatten, teilweise in der Sonne gemessen" %}
  • {% trans "Beleuchtung zwischen zwei Erfassungsläufen umgestellt (auch die Empfindlichkeit/„Gain“ pro Kanal verändert dann alle Werte!)" %}
  • {% trans "Probe einmal direkt unter der Lampe, einmal am Rand des Lichtflecks" %}

    • {% trans "Warum ist das so wichtig? Wenn zwei Messreihen (z. B. zwei Projekte) unter unterschiedlichem Licht aufgenommen wurden, können die Daten nicht direkt zusammengeworfen werden — die Plattform erkennt das im Fusions-Vergleich (Signifikanztest) und meldet die Inkompatibilität. Nur der Schwarz/Weiß-Abgleich (Abschnitt 3) schafft hier eine Brücke." %}

    {% trans "3. Der Schwarz/Weiß-Abgleich (Dark/White-Kalibrierung)" %}

    {% trans "Der Abgleich ist die Brücke zwischen verschiedenen Messungen und sogar verschiedenen Sensoren. Die Idee: Messen Sie zwei Referenzen — Schwarz (kein Licht) und Weiß (volle Reflektion) — und rechnen Sie jede eigentliche Messung auf diese Skala um:" %}

    Reflexwert = ( Messung − Schwarz ) / ( Weiß − Schwarz )

    Schwarz Dark-Referenz

    {% trans "Sensor mit abgedunkelter Öffnung messen (Deckel zu, schwarzes Tuch, dunkler Kasten). Das misst den Dunkelstrom/Offset des Detektors — das Grundrauschen, das auch ohne Licht anliegt." %}

    {% trans "Praxis-Tipp: Deckel oder lichtdichtes Tuch über die Messöffnung; je dunkler, desto besser." %}

    Weiß White-Referenz

    {% trans "Sensor auf eine weiße, diffuse reflektierende Fläche richten: handelsübliche weiße Referenz (z. B. Kalibrierkachel/Spectralon), notfalls helles, mattes Papier oder eine weiße Keramikfläche. Das entspricht „100 % Licht“." %}

    {% trans "Praxis-Tipp: gleiche Geometrie wie bei der Probenmessung (Abstand, Winkel)." %}

    • {% trans "Wann?" %} {% trans "Zu Beginn jeder Messsitzung — und immer dann, wenn sich Beleuchtung oder Temperatur merklich ändern." %}
    • {% trans "Wie oft?" %} {% trans "Mehrere Wiederholungen! Die Plattform verlangt für Fusionsprojekte mindestens 50 Wiederholungen je Referenz — aus der Streuung der Wiederholungen ergibt sich das Rauschniveau, und aus den White-Werten zweier Sensoren lässt sich die Übertragungskurve („Gain-Kurve“) zwischen ihnen berechnen." %}
    • {% trans "In der Plattform anmelden:" %} {% trans "Legen Sie die Dark- und White-Messungen als eigene Datensätze in Ihrem Projekt ab und deklarieren Sie sie im Metadaten-Editor: reference_type = dark bzw. white, n_repeats = Anzahl der Wiederholungen, reference_artifact = was Sie benutzt haben (z. B. „weiße Referenzkachel“). Erst mit dieser Deklaration kann die Plattform die Gain-Kurve berechnen und Daten aus zwei Erfassungsläufen korrekt zusammenführen." %}

    {% trans "Beispiel: Die Regressionsgleichung aus dem Bericht selbst ausrechnen" %}

    {% trans "Der Bericht liefert pro Kanal die Koeffizienten, Mittelwerte und Standardabweichungen. Mit diesem kurzen Programm rechnen Sie eine Vorhersage für Ihre eigene Messung nach:" %} 

    # Beispiel: Brix-Vorhersage mit der Gleichung aus dem Bericht
# (Zahlen bitte durch die Werte aus IHREM Bericht ersetzen)
intercept = 4.2          # aus dem Bericht: Achsenabschnitt
coefs     = [0.8, -0.3]  # Koeffizienten je Kanal
means     = [3450.0, 1900.0]  # Kanal-Mittelwerte
stds      = [120.0, 80.0]     # Kanal-Standardabweichungen
messung   = [3500.0, 1850.0]  # Ihre neue Messung (2 Kanäle)

z = [(m - mean) / std for m, mean, std in zip(messung, means, stds)]
brix = intercept + sum(c * v for c, v in zip(coefs, z))
print(f"Vorhergesagter Brix-Wert: {brix:.2f}")

    {% trans "Tipp: Genau diese Formel (y = intercept + Σ coef_i · (x_i − mean_i)/std_i) steht auch unter der Koeffizienten-Tabelle im Bericht – der Quellcode zeigt, wie sie in der Praxis angewendet wird." %}
